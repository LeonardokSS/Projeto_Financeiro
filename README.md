# Sistema de Controle Financeiro

Este projeto é um sistema simples para gerenciamento financeiro pessoal.  
Ele permite registrar gastos, visualizar metas, acompanhar gráficos e manter um painel geral de controle.  
Foi desenvolvido com **HTML, CSS, JavaScript e Node.js (Express + MongoDB)**.

## 📌 Funcionalidades

- Cadastro de gastos  
- Visualização de gastos por lista  
- Criação e gerenciamento de metas  
- Botão para adicionar valores às metas  
- Dashboard com visão geral  
- Gráficos financeiros  
- Sidebar fixa para navegação em todas as páginas  

## 🛠 Tecnologias Utilizadas

- Node.js  
- Express  
- MongoDB (MongoClient)  
- HTML5  
- CSS3  
- JavaScript  
- Method-Override  
- Fetch API
